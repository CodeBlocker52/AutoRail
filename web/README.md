# Autorail web

Landing page and app for Autorail on QDay Aevum testnet (chain 44005). Runs on mock data by default.

```bash
pnpm install
cp .env.example .env.local   # optional
pnpm dev
```

See [docs/UI.md](docs/UI.md) for routes, components and how to switch from mock to onchain.

Testnet only. tUSD8 and tQDAY are test assets with no monetary value. Contracts are unaudited.
