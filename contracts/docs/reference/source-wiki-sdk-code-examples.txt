Coming Q1 2027
The QDay SDK (@qday-io/sdk) and CLI (@qday-io/cli) launch in Q1 2027 and are not yet published on npm. Code on this page shows the planned API.

Only the TypeScript / JavaScript SDK (@qday-io/sdk) and the CLI (@qday-io/cli) are planned for Q1 2027. Go, Rust and Python SDKs are planned but not published — the package names below are placeholders and may change, so do not install look-alike packages from public registries. Example repositories will be published under github.com/qday-io.

JavaScript​

# Available Q1 2027 — not yet published on npm

npm install @qday-io/sdk

CommonJS entry: require('@qday-io/sdk').

TypeScript​

# Available Q1 2027 — not yet published on npm

npm install @qday-io/sdk

ESM + types: import { … } from '@qday-io/sdk'. Wallet, contract, and payment snippets on this site are TypeScript-first.
